# Privacy Policy — Burnout Game Jam

## 1. Overview

Burnout Game Jam is a browser-based game developed for a game jam.

## 2. Personal Data

The game is not intended to request personal information such as names, email addresses, or phone numbers from players.

The development team does not intentionally collect personal data through the game itself. This statement must be updated if analytics, external APIs, account systems, or other data collection features are introduced.

## 3. Local Storage

If the game stores settings, progress, or other gameplay information in the player's browser, this information may remain on the player's device. The exact storage behavior depends on the implemented game features.

## 4. Third-Party Services

The game may be hosted by a third-party platform. Such platforms may process technical information according to their own privacy policies.

## 5. Contact

For questions about this policy, please contact the development team through the project's GitHub repository.
