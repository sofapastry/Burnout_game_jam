# BURNOUT: Ты — Семестр — отчёт о проекте

**Мероприятие:** геймджем БрГТУ, тема *«Роли наоборот» (Roles Reversed)*
**Платформа:** браузер (ПК), в комплекте лаунчер для Windows
**Языки:** английский / русский

---

## 1. Идея

Почти в каждой игре игрок — герой, а мир пытается его остановить. Для темы *«Роли наоборот»* мы
перевернули историю, которую знает каждый студент: **ты — семестр, а студент — противник.**
Кирилл — первокурсник БрГТУ, который просто хочет сдать сессию. А ты — всё, что стоит у него на пути:
внезапные контрольные, дедлайны, напарники по групповому проекту, преподаватель физкультуры,
защита проекта и, наконец, сам Последний Экзамен.

Игрок побеждает, когда Кирилл получает незачёт. Кирилл побеждает, если сдаёт.

Персонажи основаны на людях и местах нашего университета. У каждого «босса» свой характер,
локация, реплики и стиль боя:

| Персонаж | Роль | Где |
|---|---|---|
| Шейди | студент по обмену, который взламывает расписание | главный холл |
| Нина | преподаватель физкультуры, которая никогда не проигрывала забег | стадион |
| Паша и Гриша | рэпер и сонный шутник | поточная аудитория |
| Ромчик | тусовщик, который не даёт учиться | компьютерный класс 317 |
| Маша и Соня | сплетница и стримерша | актовый зал |
| Последний Экзамен | сам конец семестра | Древо Знаний |
| Артём | друг Кирилла — единственный на его стороне | везде |

## 2. Как играть

Сюжетная кампания состоит из шести глав. Каждая глава — одна неделя семестра:

1. **Кат-сцена** знакомит с местом и персонажем, которого встречает Кирилл.
2. **Этап орды.** Твои юниты (карты твоего отряда) призываются сами вокруг Кирилла. Ты не смотришь
   сверху: ты *вселяешься* в одного из них и сражаешься от третьего лица. С помощью **Прыжка души**
   ты перелетаешь из тела в тело, а первый удар после прыжка — засада. У каждого типа юнитов два
   собственных навыка (всего 28): Напарник по проекту обнимает Кирилла, и тот не может двигаться,
   Медбол идёт на таран, Волна аплодисментов заставляет его танцевать и т. д.
3. **Короткая сцена-переход** к тому, что дальше, а затем **бой главы**:
   - **бой с боссом**, где босс — *это ты* (третье лицо, в духе souls-игр): лёгкие и сильные удары,
     два фирменных приёма, два заклинания с прицеливанием, ультимейт и твоя орда, сражающаяся рядом;
   - или другая игра: **дуэль в стиле Mortal Kombat** (Ромчик), **забег на норматив** против Нины
     или **Выступление**, где ты — Маша и Соня, которые отвлекают Кирилла вспышкой камеры и лазерной
     указкой, пока он защищает проект.
4. **Усиление:** выбери одно из трёх улучшений орды (частота появления, урон, скорость атаки,
   уровень юнитов, здоровье…). Они складываются до конца семестра.

Кирилл даёт отпор. На этапах орды он идёт к своей цели, стреляет по юнитам маркером, повышает
уровень и выбирает улучшения. В боях с боссом он играет как souls-игрок: кружит, читает твои замахи,
перекатывается сквозь атаки, лечится кофе, а Артём прибегает на помощь, когда у него мало здоровья.

Кроме сюжета есть **Быстрая игра**, **Классический** режим (исходная игра с ордой сверху) и
**Аркада** со всеми мини-играми, а также два режима **на двоих за одним компьютером**.

## 3. Как менялся дизайн (плейтесты)

Игра прошла несколько больших итераций, и каждую из них определяли друзья, которые играли и честно
говорили, что не так. Этот отзыв был самой ценной частью джема.

| Отзыв | Что мы изменили |
|---|---|
| «Скучно, похоже на мобильный tower defense» | Перешли от карточной игры сверху к **третьему лицу**. Игрок стал боссом на арене в духе souls-игр. |
| «Мы не знаем, кто все эти люди» | Добавили **пролог** и **кат-сцену для каждой главы**, которые знакомят с персонажами. |
| «Mortal Kombat покажет модели лучше, чем Shadow Fight» | Переделали дуэль в стиле Mortal Kombat с добиванием. |
| «Можно просто спамить контрольными и выиграть» | Призыв в боях с боссом стал **автоматическими волнами** с ограничением. |
| «Ставить карты сверху скучно» | **Прыжок души**: ты живёшь внутри юнитов и прыгаешь между ними. Призыв стал автоматическим. |
| «Кирилл слишком сильный, недели слишком длинные» | Перебалансировали урон и скорострельность, сократили этапы орды. |
| «Боссам нужно больше способностей, как в Elden Ring» | Каждый босс получил 2 фирменных приёма, 2 заклинания с прицеливанием и уникальный ультимейт с кинематографической сценой. |
| «Свет слишком яркий», «эмодзи выглядят дёшево» | Приглушили свечение и экспозицию, заменили все эмодзи нарисованными иконками, новый стиль интерфейса. |
| «Мячи мерцают» | Выяснили, что катящиеся мячи вращались вокруг точки на полу, а не вокруг своего центра, и проваливались сквозь пол. |

Организатору понравилась игра *The Dark Queen of Mortholme* (ты играешь за финального босса, а герой
возвращается снова и снова и учится). Мы сделали свою версию этой идеи: Кирилл может вернуться после
поражения, поговорить с тобой и стать устойчивым к тому, что его победило. После тестов мы отключили
это в основном сюжете (игрокам больше понравилось одно чистое поражение), но механика осталась в коде
как опция.

## 4. Технологии

| Часть | Что использовали |
|---|---|
| Язык | **TypeScript** (строгий режим) |
| 3D | **Three.js** (r170), WebGL |
| Сборка / сервер разработки | **Vite** |
| Персонажи | 8 моделей GLB в T-позе, автоматический риггинг скриптом на Python в **Blender** |
| Анимация | процедурная, позы задаются в коде (без файлов анимации) |
| Звук | 100% синтезируется во время игры через **Web Audio API** |
| Тесты | автоматические тесты без браузера в Node с **happy-dom**, сборка через esbuild |

Игрового движка нет. Всё — игровой цикл, сцены, упрощённая физика движения, ИИ, интерфейс — наш
собственный код поверх Three.js. Поэтому сборка маленькая (около 4 МБ в архиве), работает в любом
браузере, и мы контролируем каждую систему.

### Структура проекта

```
main.ts            фиксированный цикл обновления 60 Гц + отрисовка каждый кадр
game/flow.ts       конечный автомат игры: меню, семестр, главы, какая сцена сейчас идёт
game/week.ts       один этап орды (юниты, Кирилл, правила, интерфейс, вселение, Прыжок души)
game/rules.ts      собственные правила и шкала победы/поражения каждой недели (15 недель)
boss/arena.ts      бой с боссом от третьего лица; boss/spells.ts — эффекты заклинаний
duel/, arcade/     дуэль и мини-игры (забег, выступление, ритм-игра, раннер, подземелье, на двоих)
story/             данные кампании, кат-сцены, пролог
hero/              ИИ Кирилла и система процедурных персонажей и анимации
horde/             юниты (инстансная отрисовка), подбираемые предметы, персонажи-гости
maps/              планы этажей, расстановка объектов, навигационная сетка и поля потоков, фоновая жизнь
render/            сцена, мультяшные материалы + контуры, постобработка, эффекты
core/              синтез звука, генератор случайных чисел с зерном, голосовые реплики
ui/                интерфейс, иконки, эффекты (штампы, надписи комбо)
i18n.ts            все строки на английском и русском
```

### Системы, которые стоит пояснить

- **Фиксированный шаг времени.** Логика игры всегда обновляется с шагом 1/60 с, независимо от
  частоты кадров. Физика, перезарядки и ИИ работают одинаково на слабом ноутбуке и мониторе 144 Гц,
  а тесты повторяемы.
- **Случайность с зерном.** У каждого семестра есть зерно (seed). Расстановка объектов, события и
  решения ИИ берутся из генератора с этим зерном, поэтому прохождение можно воспроизвести (и
  поделиться им — зерно показано на финальном экране).
- **Навигация.** Карты превращаются в сетку. Кирилл и юниты движутся по **полям потоков** (карта
  расстояний до цели, построенная поиском в ширину) — это дёшево даже для множества агентов сразу.
  Препятствия «расширяются» на одну клетку, чтобы юниты не застревали в узких проходах.
- **Отрисовка множества юнитов.** Юниты одного типа рисуются через **InstancedMesh** (один вызов
  отрисовки на тип), а все статичные объекты карты объединены в несколько сеток.
- **Мультяшный стиль.** Материалы с тональной заливкой (cel shading), чёрные контуры методом
  «вывернутой оболочки» (inverted hull) и постобработка (свечение, цветокоррекция, виньетка) с
  переключателем низкого качества.
- **Персонажи.** Модели были без скелета, в T-позе. Скрипт для Blender (`tools/autorig.py`)
  автоматически добавляет скелет и веса. В игре одна система поз управляет и процедурными
  персонажами, и моделями со скелетом, а пружинное сглаживание делает движения живыми, а не
  роботизированными.
- **ИИ Кирилла (бой с боссом).** Небольшой конечный автомат (ожидание, удар, луч, перекат, кофе,
  оглушение) с правилами, которыми пользуется игрок: держать дистанцию, перекатываться, когда видит
  замах, наказывать за открытость, лечиться при низком здоровье.
- **Звук.** Музыка — пошаговый секвенсор с настроениями (меню, погоня, босс, дуэль, плач), которые
  реагируют на напряжение боя. Эффекты, колокола и хоры собраны из осцилляторов, отфильтрованного
  шума и сгенерированной реверберации.
- **Локализация.** Каждая строка на экране — ключ в `i18n.ts` с текстом на английском и русском.

## 5. Тестирование

Кроме плейтестов с друзьями, в проекте есть **автоматические тесты без браузера**, которые запускают
настоящий код игры в Node (с поддельными DOM и canvas). Они:

- проходят каждую неделю семестра ботом и бездействующим игроком (чтобы убедиться, что Кирилл всегда
  может победить),
- проходят весь сюжет от главного меню до финального экрана, нажимая настоящие кнопки,
- запускают каждый бой с боссом, каждое заклинание и ультимейт, каждую мини-игру,
- проверяют, что каждая карта полностью проходима для поиска пути.

Это позволило менять крупные системы в конце джема, не ломая игру.

```
npm run typecheck · npm run smoke · npm run smoke:arcade · npm run smoke:flow · npm run check:maps
```

## 6. Решённые проблемы

- **Автоматический риггинг моделей.** Одна модель не проходила автоматическое взвешивание в Blender
  из-за масштаба и длинных волос, касающихся рук. Мы увеличиваем модели перед риггингом, добавили
  запасной вариант через воксельную копию и исключили волосы из весов рук.
- **Локти перекручивались вместо сгибания.** Ось сгиба не совпадала с ориентацией кости; исправили,
  сгибая вокруг собственной оси Y кости.
- **Катящиеся мячи мерцали.** Сетка мяча была смещена относительно точки вращения, и при качении
  он проходил сквозь пол. Исправили, отцентровав сетку и подняв её при отрисовке.
- **Всё было слишком ярким.** Свечение цеплялось за экран проектора и белые поверхности. Подняли порог
  свечения, снизили экспозицию и запретили ярким поверхностям обходить тональную компрессию.
- **Баланс.** Каждый плейтест менял числа: скорострельность Кирилла, урон боссов, частоту волн,
  длительность недель.
